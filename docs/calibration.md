# Smart Drain TH080 Calibration

## Input Tank

0%   = ADC 0
25%  = ADC 1850
50%  = ADC 2000
75%  = ADC 2150
100% = ADC 2300

## Output Tank

0%   = ADC 0
25%  = ADC 1770
50%  = ADC 1920
75%  = ADC 2030
100% = ADC 2150

## Connection

Input TH080 Signal  -> GPIO34
Output TH080 Signal -> GPIO35

Both sensors:
VCC -> 3.3V
GND -> GND
